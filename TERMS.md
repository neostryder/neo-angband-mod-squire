# Terms of Use for the Neo Angband Squire Mod

Effective date: 2026-09-30.

Squire is an optional mod that runs inside Neo Angband and provides an autoplayer. It is disabled until enabled, and it takes the keyboard only when the player asks with the game's own Ctrl-Z activation. With a model set up, Squire keeps playing until the player takes the keyboard back or Squire stops. The model is Jev, which TypeSafe hosts, Laya, which the player runs, or another compatible server. With no model, or with the "Let a model choose what to do" switch off, a handover runs one errand and then stops issuing commands. The errands are engaging a single creature, walking out the unexplored part of a floor and, if switched on, a longer errand that carries the character until there is nothing left to do on the floor. The errands, stop conditions and other settings can be changed in the mod controls and the Squire panel. Squire has no hosted service of its own apart from the optional telemetry service at squire.rpgm.tools, run by the Squire project.

Its shipped manifest declares 21 capabilities. With them, Squire can issue commands the game already accepts and read the character, the creatures, the map, items on the floor, the current target, the inventory, spellbooks, the stores, the game turn and the message stream. It can receive combat outcomes and the player's own commands, show its panel, and register an order command with a key. When the player turns it on, it can also start a new character after a death and supply that character's birth choices. Three capabilities allow network requests: to api.typesafe.ai, to squire.rpgm.tools, and to addresses on the player's own computer or home network. The game's host makes those requests for Squire.

Squire makes a network request only for a feature the player sets up. Requests to the chosen model server carry the character's situation, the persona and its backstory, lessons Squire has learned, its aims, the player's orders, the names of viewers who gave orders and, after a death, the cause and the last few plans. Knight's Lessons, which is on by default, sends these requests while the player plays as well. Training sends to Laya, collecting viewers' orders from an address the player enters, and telemetry are each off until the player turns them on. Telemetry sends finished runs at the level the player picks, and sends a backstory only with separate consent.

Squire stores data in the game's storage on the player's device. For the install, it keeps its settings, the persona library and family records. With each character, it keeps that character's persona, orders and run journal. It also keeps decision logs, run reports, Laya training rows, the apprentice notebook, an install identifier and telemetry waiting to be sent. In the desktop app, the app keeps a Jev API key encrypted. In a browser, the key is kept in page storage, where other mods in the same page could read it. Squire makes its own random choices, such as rolling a random persona, varying persona strength between decisions, or passing traits to an heir. It does not draw from the game's random number generator, so the game's own random sequence is unaffected.

Handing a character to any autoplayer, including Squire, permanently marks that save as having used one, and the character can no longer earn a high score. The game sets that mark, not the mod; it applies from the moment the keyboard is handed over and cannot be cleared. The player is responsible for deciding whether to hand over a character and for keeping an export or backup of local game data.

Installing or updating the mod from the in-game mod manager can fetch its public files from GitHub; those requests come from the Neo Angband host's mod manager. The core Neo Angband Terms and Privacy Policy cover that shared host behavior, including local storage, update checks, and the risks of optional third-party mods.
